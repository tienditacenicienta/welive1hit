# ONE HIT — tienda online (nueva dirección)

Sitio responsive en español que recupera el concepto original de ONE HIT: “Sueña. Créalo. Y vive.”, el artista que existe en cada persona y la ropa como compañera para crear y vivir cada momento.

## Archivos
- `index.html`
- `styles.css`
- `script.js`
- `one-hit-hero-mockup.png` — mockup visual editorial de polos blanco, gris y negro.
- `one-hit-pack-mockup.png` — mockup visual de pack de tres polos.

## Publicar
Sube todos los archivos a la raíz de tu repositorio GitHub. En Cloudflare Pages conecta el repo, usa Framework preset `None`, deja el comando de build vacío y usa `/` como directorio de salida.

## Antes de vender
1. En `script.js`, cambia `https://wa.me/?text=` por `https://wa.me/519XXXXXXXX?text=` usando el número comercial de ONE HIT.
2. Sustituye los mockups de concepto por fotografías reales de las prendas finales antes de cobrar pedidos.
3. Confirma composición, medidas, colores, stock, precio y política de cambios.
4. El carrito envía el pedido por WhatsApp; no procesa pagos ni reserva stock automáticamente.
