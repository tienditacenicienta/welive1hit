# ONE HIT — Mobile adaptation V1

This package adds a mobile-only layout using CSS media queries (`max-width: 700px`, plus a narrow-phone refinement).

Desktop layout is unchanged. The JavaScript, product data, images, logo, carousel behavior, size selection, quantity control and cart logic are retained.

Mobile changes:
- A taller vertical hero to avoid squeezing the product controls into the model area.
- Headline moved into the upper-middle area, in front of the model but clear of the face.
- Model resized and repositioned.
- Brand logo kept behind the model.
- Arrows moved away from the purchase controls.
- Product details, sizes, quantity and add-to-bag button arranged in a more readable vertical composition.

Upload the project files from this ZIP to the existing GitHub repository. All files are included; `src/app.js` and `public/` are unchanged.
